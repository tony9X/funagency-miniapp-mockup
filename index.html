💡 UX Design Notes
Stat hero up top Số tiền đang kiếm hiện ngay đầu màn hình. Mở MiniApp = thấy tiền = retention boost.
Tier progress visible 3 tier (Starter/Growth/VIP) — bar progress motivate user upgrade.
Quick actions 2x2 4 hành động chính (Share / Withdraw / Network / Stats). Native-feeling tabs.
1-tier flat list Chỉ direct refs (no cascade). Đơn giản, transparent, không MLM-vibe → trust ↑.
Active vs Inactive split Section riêng cho ref đang chạy + ref tạm dừng. User biết rõ status từng người.
Per-ref earnings + start date Show từ tháng nào → user thấy được lifetime value của 1 ref. Motivation để giới thiệu thêm.
Bar chart 6 months Trend visualization → user thấy growth → motivate scale network.
Leaderboard FOMO Top 10 tháng. Show user position. Top 3 = gold/silver/bronze. Gamification.
Available + Pending split User cần biết tiền nào rút được, tiền nào đang hold. Transparent = trust.
TX history infinite List có thể scroll, cho phép user verify từng giao dịch. Anti-fraud trust.
Quick amount chips $100/$300/$500/Max — giảm typing trên mobile.
Confirmation step Show wallet partial hash để user verify. Safety check.
QR + copy + native share 3 cách share. QR cho gặp face-to-face, copy cho chat, native cho mọi app.
Pre-written messages User lười viết → cho 2-3 template ngắn ready-to-paste.
